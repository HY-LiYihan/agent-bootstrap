One-line setup for model CLIs.

Paste your token and base URL, choose an agent and operating system, then copy a ready-to-run install command. Values stay in this browser tab and are not sent anywhere by this page.

Stable target Commands use HY-LiYihan/agent-bootstrap@stable, so the public command does not need to change when the implementation is updated.
